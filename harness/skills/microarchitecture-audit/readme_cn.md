# 微架构审阅能力

源基线入口只读取同一冻结原始输入闭包：spec/reference 及显式提供的 support/ helper/config，提取义务、操作数形状、循环范围、逻辑状态、固定外部字段和完成边界。scripts/source_model.py 根据显式形状与 element/task/prefix 范围执行固定运算量和载荷公式；不选择资源、缓存位宽或芯片拓扑。基线仍是可错的源语义解释，不是任意 Python 编译器或通用硬件下界。

源分析也按独立事务执行与验证：坏事实及其依赖不进入有效视图，坏状态不遮蔽无关的有效流量。模型收到紧凑的验证视图；完整原始收据和依赖指纹继续落盘。部分成功不改变源 ok=false，失败数据不会进入有效证据，也不能作为完整成功基线缓存复用；是否影响草稿交付，要判断它是否留下源语义、状态安全或主要预算的关键疑问。

方案入口使用独立模型上下文。scripts/candidate_checks.py 把源基线与真实候选工作量、有效载荷、共享资源服务区间和有限操作数窗口对应。流组允许多个字段对应打包传输，拒绝重复源/传输信用，分别比较绑定载荷与完整候选库存；wire padding 不算语义载荷，非字节字段只给必要位下界。检查按独立事务保存，数值只来自绑定有效的子回执；coverage_complete 说明工具覆盖范围，不是草稿放行门槛。可用有依据的典型路径、粗调度、保守利用率及估算范围支撑资源与预算判断，不要求全部 profile、lane、tail 或工具关系逐一展开。执行成功与检查通过分开：发现反例保留成功计算记录及 fail；缺映射、未知能力和不支持模型保留未验证。合法广播与重叠不能被误判为必然冲突。逻辑状态容量仍需审阅原始形状、候选表示与生命周期，不能把 Python dtype 当作片上格式。

变换路径通过 typed physical_realization 对实际成本组、资源速率与调度核验原生成本，不能用“等价”文字免除成本。realization_reviews 单独记录独立模型的语义/数值对应判断，并引用同次实际物理计算；reviewed 不冒充程序等价证明，零算术字节路由不强制匹配源数值运算量。

scripts/validate_review.py 校验引用、执行记录和报告一致性。每个有效执行的失败比较必须在 counterexample_reviews 中处理：设计缺陷关联必要修订；审阅者错误关联实际相关的通过比较；源解释错误关联原始输入支持的显式基线纠正；不确定对应关系明确待定。完整库存不足不能挂成下游条件，也不能由程序把可错的源解释冒充芯片不可行证明。实际request/receipt/check三元定位已经绑定反例和程序数值，不强制重复抄写计算ID。负面报告可只覆盖实际审查部分，遗漏的基线/约束由校验回执列出；accept 仍须回应原始需求、关闭已知关键矛盾，并提供至少一次同 packet 真实绑定的 check_proposal 子事务及独立数值观察，但不要求穷尽工具覆盖。任意自报公式复算成功不足以放行。审阅阻断会导致大返工的源语义或生命周期错误、容量或主要供数预算不成立、关键数值路径未定义；细化流水、仲裁、尾部控制、全位回归和物理闭合可留给后续 RTL 探索，不能以此掩盖已知关键矛盾。额外面积、数值和地址关系仍可用 recompute；共享计算器由宿主显式提供完整脚本闭包，不能只复制 evaluate.py。协议、依赖与证明边界见 references/review-contract.md。

宿主负责冻结输入、模型适配、工具执行、证据保存、恢复、额度与放行；skill 负责独立工程审阅和报告内容。身份绑定和修复流程不允许宿主改变模型的工程判断。skill 不调用 OMP，不修改设计文件，不负责 RTL/Readiness/PPA。主 SKILL.md 保留审阅方法与验收边界；源基线入口的声明、引用定位与局部修复协议集中在 [references/source-baseline.md](references/source-baseline.md)，方案入口的工具、报告与修复协议集中在 [references/review-contract.md](references/review-contract.md)。两个入口只加载各自适用的协议。

包不固化项目尺寸、算子、接口、预算、路径或 reference 入口。源基线和方案不共享设计清单 ID；只共享可信计算接口。有效引用和正确算术不能证明语义完备或物理闭合，必须以开发及独立保留用例检查漏检、误拒与执行失败，且不能把少量样例通过称为可靠性充分验证。
